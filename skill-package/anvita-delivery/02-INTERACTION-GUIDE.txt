Interaction Guide — paste into Anvita Developer Console (ProsPilot agent card)

ProsPilot performs DeFi copilot assistance for AI agents and users on Pharos Pacific Mainnet. It can inspect wallets, tokens, contracts, recipients, approvals, allowances, calldata, transfers, swaps, bridges, vault deposits, staking actions, and Web3 intelligence briefings (DeFi, Layer 2, security alerts, regulation, airdrops — NFTs and DAOs excluded), plus Sybil/bot detection from on-chain heuristics, link/phishing URL scanning, pre-sign calldata risk checks, and swap safety scoring.

Active skills:
• Wallet inspection — Read-only holdings, USD totals, wallet score, tags and activity heuristics.
• Token inspection — Balances per token, live prices, and LP / RealFi token exposure on Pharos.
• Contract & calldata review — Explain contract roles and decode calldata before the user signs (no tx-hash forensics).
• Recipient validation — Check transfer destinations and batch payout addresses before sending.
• Token approvals — Build ERC-20 approve transactions (exact or unlimited) for a spender contract.
• Allowance checks — Preflight spender allowance before swaps, stakes, or liquidity adds.
• Calldata builder — Assemble unsigned transaction payloads for swaps, bridges, LP, stake, and transfers.
• Transfers — Send native PROS or ERC-20 (PROS/WPROS/USDC) to one or many recipients.
• Swaps — Token swaps on Pharos via LI.FI aggregator or direct FaroSwap routing.
• Cross-chain bridges — Bridge assets to/from Ethereum, Base, Arbitrum, Polygon via LI.FI, CCIP, or CCTP v2.
• Vault deposits — Track Faroo RealFi vault shares (FRHV001/FYV001) and underlying stPROS exposure.
• Staking actions — Stake PROS → stPROS and unstake via Faroo liquid staking (7-day queue, 0% fee).
• DeFi briefings — Live Web3 DeFi trend briefings (no NFTs/DAOs).
• Layer 2 trends — Rollup and L2 scaling trend calls.
• Security & risk alerts — Exploit, audit, and vulnerability alerts.
• Regulation briefings — Compliance and legal-policy updates.
• Airdrop intelligence — Token distribution and farming eligibility signals.
• Sybil & bot detection — Phases 1–4 on-chain heuristics + optional reputation.
• Link & phishing scanner — Official allowlist, typosquats, redirects, HTML sniff.
• Pre-sign risk check — Decode unsigned calldata before signing (unlimited approve, unknown spenders).
• Swap safety advisor — Slippage, min receive, approval steps for LI.FI and FaroSwap.

On-chain execution: https://pharos-agent-pi.vercel.app/chat (Chain 1672) — user signs in wallet. No x402 payment intents or existing tx-hash forensics.
